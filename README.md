# Information_System_Project-CANN_Pizzeria
A complete pizzeria management system developed in Zoho Creator as part of an Information Systems course project.

## Overview
The system was designed to manage the full operational process of a pizzeria- from receiving customer orders, managing employees and shifts, tracking suppliers and inventory, to financial monitoring and dashboards.
Developed to demonstrate process integration, database design, and workflow automation using Deluge scripting in Zoho Creator.

## Main Features
### Order Management
- Separate modules for Online and In-Place Customer Orders
- Automatic linking between customers, orders, and payments  
- Includes detailed order lines and total price calculation  
- Integration with Finance Records to automatically update profits and expenses  

### Employee Management
- Employee database with contact info, position, hourly rate, and active status  
- Shift assignment system linked to predefined Shift Types(morning, evening, delivery, etc.)  
- Absence tracking and connection between shifts and employees  

### Inventory and Supplier Management
- Inventory table with real-time tracking of current stock, safety stock, and shortage alerts  
- Supplier Orders system with automatic inventory updates upon order receipt  

### Dashboards and Reports
- Dynamic reports for customers, suppliers, inventory, orders, and finance  
- Management Dashboard with visual summaries  
- Financial Dashboard for tracking revenue and expenses over time  
- Customers Map for quick access to operational insights  

## Installation and Usage
To explore or test the application in Zoho Creator:
1. Download the file `CANN_Pizzeria.ds` from this repository.  
2. Log In to Zoho Creator 
3. Click **Create New App → Import File → From File (.ds)**.  
4. Upload the downloaded file.  
5. Once imported, the system will be fully accessible within your Zoho Creator workspace.

This allows you to explore all forms, workflows, reports, and dashboards included in the system.
Important: The imported .ds file includes only the application's design and logic, without preloaded data. Users should manually enter sample records after import to test the system’s functionality.
